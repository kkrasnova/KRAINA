

Ця папка містить матеріали для маркетплейсів і презентації продукту.



- `app-description-uk.md` — опис застосунку українською.
- `app-description-en.md` — опис застосунку англійською.
- `asset-checklist.md` — чекліст маркетингових матеріалів (скріни/банери/відео).



1. Короткий опис (80-170 символів).
2. Повний опис (до 4000 символів).
3. 5-8 скріншотів ключових екранів.
4. Іконка застосунку.
5. Promotional banner (за потреби).
6. Preview video (опційно).



Текстові матеріали готові у цій директорії. Графічні/відео матеріали додаються окремими файлами.
