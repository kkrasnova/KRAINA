

Ця папка підготовлена для швидкого формування store-ready матеріалів.



- `ios/` — скріншоти для App Store
- `android/` — скріншоти для Google Play
- `banners/` — промо-банери (за потреби)
- `video/` — preview/demo відео (за потреби)



Використовуйте єдиний формат:

`<platform>_<order>_<screen>_<lang>.<ext>`

Приклади:

- `ios_01_auth_uk.png`
- `ios_02_home_uk.png`
- `android_01_auth_en.png`
- `android_02_route_en.png`



1. Авторизація
2. Головний екран / стрічка
3. Картка локації
4. Побудова маршруту
5. Профіль
6. Повідомлення (опційно)
7. Налаштування / мови (опційно)
8. Соціальний екран (опційно)



- iOS: 1290x2796 (або інші офіційно підтримувані App Store)
- Android: 1080x1920 або 1242x2208
- Банери: 1920x1080 (горизонтальний), 1080x1920 (вертикальний)
- Відео: mp4, 15-30 сек, H.264
