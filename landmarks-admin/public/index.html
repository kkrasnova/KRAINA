AI: додати локації з Wikipedia

Пиши блоками: країна → місто → пам’ятки (з вулицею через «—»). Можна кілька країн і міст в одному тексті. AI збере тексти/фото з Wikipedia, перекладе на всі мови застосунку і опублікує без оновлення App Store.

Де що лежить у JSON

            
    
              
  • regions — міста / регіони. Усередині — landmarks[] пам’ятки з координатами.
    • 
              
  • Кожна пам’ятка: titleUk, titleEn, lat, lng, описи, galleryUris (URL з вкладки Медіа).
    • 
              
  • Імпорт готового файлу — Імпорт. Експорт копії — Експорт.
    • 
            

            

              Мінімальний приклад фрагмента
              
"regions": {
  "kyiv": {
    "id": "kyiv",
    "titleUk": "Київ",
    "landmarks": [
      {
        "id": "example",
        "titleUk": "Назва",
        "lat": 50.45,
        "lng": 30.52,
        "galleryUris": ["https://..."]
      }
    ]
  }
}

Перегляд пам’яток

                

                  Зліва — усі пам’ятки: пошук, редагування, видалення. Справа — деталі (текст, усі фото, сторінки історії як у застосунку) і картки прев’ю.
                  Фото: thumbUri, galleryUris, фото сторінок; завантаження — вкладка Медіа.
                

              

            

            

              
              
            

            

              

                Порожньо, бо в JSON немає жодного елемента в
                regions.*.landmarks[] (на сервері міг зберегтися порожній бандл). Відкрийте
                Бандл локацій → імпортуйте файл як у застосунку, або натисніть кнопку нижче — після цього натисніть
                Зберегти.
