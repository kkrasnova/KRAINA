Швидка довідка

Де що лежить у JSON

  • regions — міста / регіони. Усередині — landmarks[] пам’ятки з координатами.
  • Кожна пам’ятка: titleUk, titleEn, lat, lng, описи, galleryUris (URL з вкладки Медіа).
  • Імпорт готового файлу — Імпорт. Експорт копії — Експорт.
Мінімальний приклад фрагмента 
"regions": {
  "kyiv": {
    "id": "kyiv",
    "titleUk": "Київ",
    "landmarks": [
      {
        "id": "example",
        "titleUk": "Назва",
        "lat": 50.45,
        "lng": 30.52,
        "galleryUris": ["https://..."]
      }
    ]
  }
}

Перегляд пам’яток

Зліва — список усіх пам’яток із пошуком і швидке редагування полів (запис у JSON). Справа — картки прев’ю. Фото беруться з thumbUri, galleryUris, story.*Uri; нові файли — вкладка Медіа.

Порожньо, бо в JSON немає жодного елемента в regions.*.landmarks[] (на сервері міг зберегтися порожній бандл). Відкрийте Бандл локацій → імпортуйте файл як у застосунку, або натисніть кнопку нижче — після цього натисніть Зберегти.
