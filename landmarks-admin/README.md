



1. Підніміть бекенд: `cd backend && npm run dev` (порт `3000`, змініть у `PORT` за потреби).
2. Відкрийте в браузері: **`http://localhost:3000/landmarks-cms/`** (той самий `PUBLIC_BASE_URL`, що в `.env`).
3. Після оновлення коду CMS зазвичай достатньо звичайного оновлення (F5): сервер віддає **заголовки без кешу** для `/landmarks-cms`. Якщо браузер все одно тримає старе — натисніть **«Оновити без кешу»** у шапці або зробіть жорстке оновлення (Safari/Chrome: **Cmd+Shift+R**).



- **Імпорт** — кнопка «Імпорт з файлу» підставляє JSON у редактор (з підтвердженням, якщо там уже є текст).
- **Експорт** — завантаження `kraina_landmark_bundle_<дата>.json` з поточного вмісту редактора.
- **Форматувати / Перевірити** — pretty-print і базова перевірка (`regions`).
- **Зберегти** — `PUT` на сервер; **Ctrl/Cmd+S** теж зберігає.
- **Медіа** — вкладка з сіткою прев’ю, копіювання URL, відкриття, видалення.
- **Сесія** — після входу токен у `sessionStorage`; при наступному відкритті сторінки сесія відновлюється.
- **API** — вкладка з URL публічного бандла.



- Потрібен **користувач у PostgreSQL** з полем `users.role = 'admin'` (звичайний логін `POST /api/auth/login` з email + password **або** Google через кнопку на сторінці логіна).
- Локальні «вбудовані» адміни в застосунку **не** підходять — це **окремі** акаунти в БД.
- У вкладці **Команда** існуючий адмін може додати нового за email. Далі нова людина заходить Google цією поштою (або email+пароль).

Щойно отримавши адміна, зробіть, наприклад:

```sql
UPDATE users SET role = 'admin' WHERE email = 'your@email.com';
```

або з терміналу:

```bash
cd backend
node scripts/create-admin.mjs your@email.com YourPassword123
```



- **Редактор JSON** — повний знімок (формат, як `saveAdminLocationBundle` на клієнті): `homeCountryOrder`, `regions`, …
- **Завантаження фото** — файли в `UPLOAD_DIR/landmark-content/media/`, публічна URL:  
  `{PUBLIC_BASE_URL}/static/landmark-content/media/…` — вставляйте в `story`, слайди, `galleryUris` тощо.
- **Публічне API для додатка** (якщо `LANDMARK_BUNDLE_PUBLIC_GET` не `0`):  
  `GET /api/app/landmark-content/bundle` — тіло = збережений бандл (порожньо, якщо ще нічого не публікували).



У полі «API» на сторінці логіна вкажіть базу, напр. `https://api.example.com` (і додайте цей `Origin` у `CORS_ORIGINS` на сервері).



- Увімкніть `CORS_ORIGINS` з доменом, де крутиться веб-адмінка, або сховайте UI за **VPN / тим самим origin** (reverse proxy, що проксить і `/` і API).
- Розгляньте `LANDMARK_BUNDLE_PUBLIC_GET=0`, якщо бандл не повинен бути публічним, доки клієнт не вміє авторизовано забирати дані.
