

Вітаємо в оновленій соціальній мережі! Тепер ви можете:





1. Перейти на **"Дослідити людей"** в меню
2. Пошукати користувача за іменем
3. Натиснути **"Слідкувати"** або **"Запросити"** (для приватних профілів)



1. Перейти на **"Чати"** в меню
2. Натиснути **"+"** → **"Новий чат"**
3. Введіть нікнейм користувача (напр. `@anna`)
4. Почніть розмову!



- **Запити на підписку** → Вкладка "Запити на підписку" у профілі
- **Чати від незнайомців** → Вкладка "Запити" у "Чатах"







```
Frontend (React Native)
  ↓
Firestore (реал-тайм)  ←→  Firebase Auth
  ↓
Backend API (Node.js)
  ↓
PostgreSQL (надійність)
```



- **socialApi.js** - управління підписками
- **messageApi.js** - управління чатами
- **firestore.rules** - безпека доступу
- **firestore.indexes.json** - оптимізація запитів



1. Підписки зберігаються у **Firestore `socialFollows`** (публічне) + **Postgres `follows`** (надійність)
2. Запити на підписку у **Firestore `socialFollowRequests`** (затримується)
3. Повідомлення у **Firestore `messageThreads`** (реал-тайм)
4. При зміні підписки - автоматична синхронізація з Postgres

1. Користувач A: **Слідкувати** за користувачем B
   - Якщо B публічний → підписка одразу
   - Якщо B приватний → запит на підписку

2. Користувач B: **Прийняти** запит
   - Обидва автоматично підписані один на одного (друзі)



1. Користувач A: **Новий чат** → введіть @username
2. Користувач A: Надіслати повідомлення
3. Користувач B:
   - Чат з'являється у "Запити" (якщо не взаємні друзі)
   - Чат з'являється у "Чати" (якщо взаємні друзі)





- ✅ Усі операції вимагають Firebase Auth
- ✅ Повідомлення видні лише учасникам
- ✅ Приватні профілі вимагають прийняття запиту
- ✅ Подпислиці не можна підійти іншомую користувачу

| Запит не приходить  | Почекайте 5 сек і оновіть                            |
| Помилка індексу     | Запустіть `firebase deploy
