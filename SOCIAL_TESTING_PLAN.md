





**Сценарій A: Публічний профіль**

1. Користувач A відкриває профіль користувача B (публічний)
2. Натискає "Слідкувати"
3. ✅ Стан змінюється на "Буде слідкувати"
4. ✅ B бачить A у своєму списку "Слідкувачі"
5. B натискає "Слідкувати A"
6. ✅ Обидва бачать один одного як взаємні друзі

**Сценарій B: Приватний профіль**

1. Користувач A відкриває профіль користувача B (приватний)
2. Натискає "Запросити підписку"
3. ✅ Стан змінюється на "Запрос надіслано"
4. ✅ B отримує запит у розділі "Запити на підписку"
5. B натискає "Прийняти"
6. ✅ Обидва автоматично підписані один на одного
7. ✅ Чат переходить з "Запити" до "Чати"



1. Відкрити "Дослідити людей" (DiscoverPeoplePage)
2. ✅ Показуються top профілі (без пошуку)
3. Ввести імʼя користувача у пошук
4. ✅ Результати оновлюються у реальному часі
5. ✅ Показується статус підписки для кожного
6. Натиснути на профіль
7. ✅ Відкривається повна інформація (слідкувачі, слідкування, друзі)



**Сценарій A: Перший неповідомний чат**

1. Користувач A відкриває "Новий чат"
2. Вводить ім'я B (@bob)
3. ✅ Чат створюється
4. A надсилає повідомлення "Привіт"
5. ✅ Повідомлення видно у потоці
6. ✅ Діалог переходить до списку "Чати" (не "Запити")

**Сценарій B: Чат з неслідкуючим користувачем**

1. Користувач C отримує чат від A (якого не слідкує)
2. ✅ Чат z'являється у розділі "Запити"
3. C може читати і відповідати
4. Коли C відправляє повідомлення
5. ✅ Чат автоматично переходить до "Чати"
6. ✅ Обидва бачать чат у звичайному списку

**Сценарій C: Зі взаємними друзями**

1. A і B вже підписані один на одного
2. A запускає новий чат з B
3. ✅ Чат відразу разу у списку "Чати"
4. ✅ Жодних "Запитів" або затримок



| Сценарій                        | Виявіть       | Результат                       |
| 
| A segueix B, B no segueix A     | A пише B      | Діалог в А - Чати; у В - Запити |
| A и B взаємні друзі             | A пише B      | Обидва в Чатах                  |
| A и B не знайомі, A першим пише | A пише B      | Dibond pendência                |
| B отримав запит від A           | B (неприйняв) | A у списку "Запити на підписку" |



**Перевірка:**

1. Користувач A приймає запит на підписку з B
2. ✅ Одразу 2 ребра у Firestore (A→B, B→A)
3. За 2-5 секунд ✅ Дані синхронізуються в Postgres
4. Перевірити API endpoint:
   ```bash
   curl -H "Authorization: Bearer $JWT" \
     https://api.kraina.app/api/social/mutuals
   ```
   ✅ Видно B у списку



| Помилка                   | Тест                                 | Очікуваний результат          |
| 
| Сервер недоступний        | Відключити інтернет                  | "Помилка з'єднання"           |
| Користувач не знайдений   | Пошук "@nonexistent"                 | "Користувача не знайдено"     |
| Спроба слідкувати на себе | Натиснути слідкувати на свій профіль | Заблокувано (не видно кнопка) |
| Подвійне натискання       | Двічі наивність слідкувати           | Лише одна операція            |
| Дебаунс пошуку            | Швидко вводити текст                 | Не більше N запитів/сек       |





```bash

JWT="$(firebase auth:export 


curl -H "Authorization: Bearer $JWT" \
  https://api.kraina.app/api/social/mutuals


curl -X POST -H "Authorization: Bearer $JWT" \
  -H "Content-Type: application/json" \
  -d '{"username":"testuser"}' \
  https://api.kraina.app/api/social/follow


curl -H "Authorization: Bearer $JWT" \
  https://api.kraina.app/api/messages/threads


curl -X POST -H "Authorization: Bearer $JWT" \
  -H "Content-Type: application/json" \
  -d '{"content":"Hello"}' \
  https://api.kraina.app/api/messages/threads/{threadId}/messages
```



1. Перейти в `Firebase Console` → Project
2. Переглянути Collections:

   - `socialFollowRequests` - запити
   - `messageThreads` - чати
   - `messageThreads/{id}/messages` - повідомлення
